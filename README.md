# Project Orion: Enterprise Network Architecture

Designed and deployed a scalable enterprise network in Cisco Packet Tracer featuring VLAN segmentation, inter-VLAN routing, multilayer switching, static routing, and centralized network services.

> **🚧 Project Status:** This project is currently under active development. This repository documents the engineering process from initial network design through final deployment, with configurations, screenshots, and testing added as each milestone is completed.
